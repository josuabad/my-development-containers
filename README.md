# My Development Containers

Este repositorio contiene Dockerfiles y archivos docker-compose para diversos entornos de desarrollo.

Los entornos disponibles se irán actualizando a siempre que sea necesario. Actualmente, se incluyen los siguientes entornos:

- **Jupyter Notebook**: Montado sobre Python 3.14 con la librería jupyterlab expuesta en el puerto 8888.
- **Python 3.14**: Desde la imagen oficial de python:3.14-slim
- **Apache Spark**: Spark 4.2.0 + Python 3.14
- **TensorFlow**: Python 3.12 + TensorFlow 2.15.0 + JupyterLab

Nuevos entornos serán agregados a medida que se desarrollen y se compartan.
